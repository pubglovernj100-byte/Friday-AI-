# FRIDAY Android Starter

A minimal native Android starter project for FRIDAY. This is a UI-only starter (no AI API, voice, web search, memory, or device automation integrated yet).

## Build APK on GitHub Actions
1. Upload the contents of this project into your GitHub repository root (not the containing folder).
2. Keep `.github/workflows/android.yml` in place.
3. Open Actions > FRIDAY Android APK Build > Run workflow.
4. When successful, open the run and download `FRIDAY-debug-apk` artifact.

Package: `com.friday.ai`
